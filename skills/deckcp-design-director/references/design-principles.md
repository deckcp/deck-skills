# Design Principles — how to make the deck feel art-directed

## 1. Design is a system of decisions

Polish comes from consistency of intent: scale, spacing, alignment, image treatment, color jobs, hierarchy, and rhythm working together.

Do not solve weak composition by adding decoration.

Prefer this order:

1. improve hierarchy
2. improve scale contrast
3. improve whitespace
4. improve alignment
5. choose a stronger image / crop
6. simplify containers
7. only then add a graphic device if the system calls for one

## 2. One slide, one dominant idea

A slide may contain several supporting facts, but one idea should visually dominate.

The audience should understand the intended takeaway in roughly two seconds from the headline + focal element.

## 3. Use scale, not ornament, to create drama

Strong decks often achieve visual interest through:

- a large type contrast
- an unexpected crop
- an asymmetric split
- a deliberate empty zone
- one oversized number
- a strong image-to-text ratio
- a repeated alignment edge

rather than adding icons, borders, blobs, or gradients.

## 4. Negative space is active

Empty space is not unfinished space. It creates hierarchy and perceived confidence.

Do not fill the canvas because there is room.

## 5. Repetition can be premium

Repeated case-study, product, location, or comparison pages can feel highly designed when the repetition is intentional and the content changes inside a stable frame.

Consistency is not the same as monotony.

## 6. Distinctiveness must be source-specific

A signature move should come from one of:

- the source brand
- a reference deck
- the product UI
- the content itself
- a deliberately synthesized visual thesis when no brand exists

Never add a signature device just because other generated decks use one.

## 7. Content determines archetype

Use semantic layout choices. A table is for rows × columns. A timeline is for sequence. A comparison is for contrast. A statement page is for a single decisive claim.

Do not translate every idea into cards.

## 8. A deck is a sequence, not twelve isolated posters

Design the rhythm across slides:

- where density rises and falls
- where imagery appears
- where evidence peaks
- where a repeated structure helps comparison
- where a chapter turn needs stronger punctuation

The whole deck should feel composed when reduced to thumbnails.
